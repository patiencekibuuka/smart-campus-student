# Smart Campus Student Management and Academic Information System

## Project Description

Smart Campus is a web-based student management and academic information system developed using Java Spring Boot. The system helps manage student academic information and provides modules for students, courses, registration, attendance, and results.

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* Thymeleaf
* MySQL
* HTML and CSS
* Maven
* Git and GitHub

## Main Features

* Student Management
* Course Management
* Course Registration
* Student Attendance
* Student Results
* Academic Information Dashboard
* MySQL Database Integration

## System Modules

### Student Management

Allows users to add and view student information.

### Course Management

Allows course information to be managed.

### Course Registration

Allows students to register for available courses.

### Attendance

Allows student attendance information to be recorded and managed.

### Results

Allows student academic results to be recorded and viewed.

## How to Run the Project

1. Start MySQL using XAMPP.
2. Make sure the `smart_campus` database exists.
3. Open the project in VS Code.
4. Open the terminal in the project folder.
5. Run:

```text
.\mvnw.cmd spring-boot:run
```

6. Open a web browser and visit:

```text
http://localhost:8080
```

## Database

The system uses MySQL as its database. The database name is:

`smart_campus`
